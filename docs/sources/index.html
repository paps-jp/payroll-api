出典と検証方法(データの信頼性について)

最終更新: 2026年11月6日 · 出典: 公式資料(協会けんぽ・日本年金機構・厚生労働省・国税庁) · 出典と検証方法

すべての料率は、協会けんぽ・日本年金機構・厚生労働省・国税庁の公式資料をもとにしています。源泉所得税は国税庁の計算例と税額表の値240件を自動テストで再現し、料率は毎週、公式ページと自動で照合しています。確認が弱い項目は「確認中」と表示します。

データの作り方と検証

  • 出典は公式資料のみ: 協会けんぽ、日本年金機構、厚生労働省、国税庁の公表資料を使っています。個々の率に出典URLと「確認済みか」の印を付けています(API の /v1/revisions でも取得できます)。
  • 複数の資料で突き合わせ: 協会けんぽの料率は、隣り合う年度のページ(前年度の欄と当年度の欄)で相互に照合しています。令和8年度の雇用保険料率は、厚生労働省の公式PDFと全区分で一致を確認しています。
  • 源泉所得税は240件の検算: 国税庁の『源泉徴収のあらまし』『税額表』に載っている計算例・税額表の値240件を自動テストにかけ、平成28年分〜令和8年分のすべてで再現できることを確認しています。
  • 毎週の自動チェック: 協会けんぽ・厚生労働省・国税庁の公開状況を毎週確認し、データとの相違や、新しい年度の公開があれば検知します。
  • 確認が弱い項目は明示: 標準報酬月額の等級の境界額、平成28年度(2016年3月分)の健康保険料率、子ども・子育て拠出金率の2015年4月・2016年4月は、出典が1つ、または間接的なため、「確認中」として扱っています。

対象範囲と注意

  • 協会けんぽ管掌の健康保険のみです。組合健保・共済組合は対象外です。
  • 賞与、随時改定、産休・育休中の免除、労災保険、年末調整、日額表は未対応です。
  • 令和2〜7年分の源泉所得税(乙欄)は、国税庁の算式が月額表(税額表)と約29万〜43.7万円付近の一部の行で最大数千円ずれます(算式のほうが大きい)。本サービスは算式どおりに計算します。
  • 計算結果は目安です。法令や公式の発表が優先されます。
