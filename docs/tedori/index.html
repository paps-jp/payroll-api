よくある質問

月給30万円の手取りはいくらですか?

東京都・35歳・扶養なし・令和8年度の場合、手取りは約249,590円です(住民税を除く)。社会保険料42,570円、雇用保険料1,500円、所得税6,340円が引かれます。扶養が1人いると、所得税が下がり手取りは約251,210円になります。

年収500万円の手取りはいくらですか?

ボーナスなし・東京都・35歳・扶養なし・令和8年度で、手取り年収は約4,131,192円(月額約344,266円)です。住民税は含まれていません。

40歳を過ぎると手取りは減りますか?

40歳以上65歳未満は介護保険料がかかるため、手取りが減ります。月給30万円の場合、35歳の手取り249,590円に対し、45歳では247,250円(約2,340円減)です。

この手取りに住民税は含まれていますか?

含まれていません。住民税は前年の所得をもとに市区町村が決め、毎年6月ごろに通知されます。通知の月額を、表の手取りから差し引いてください。

ご利用上の注意掲載内容は公式資料をもとにした目安です。実際の給与計算では、最新の公式資料で確認してください。組合健保・共済は対象外で、賞与・年末調整も含みません。
