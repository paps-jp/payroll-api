payroll-api

社会保険料率・雇用保険料率・源泉所得税の参照 / 保険料計算 / 改定検知を行う REST API と MCP サーバー。2016年からの履歴に対応しています。

REST APIMCP収録データ計算の考え方注意事項改定への追従 GitHub

概要

協会けんぽ管掌の健康保険・介護保険、厚生年金、子ども・子育て支援金/拠出金、雇用保険、給与の源泉所得税(月額表 甲欄・乙欄)の料率と計算を、同じデータから返します。住民税は自治体の通知額を入力として受け取り、手取りまで一括で計算できます。

  • エンドポイント: https://payroll-api.paps.jp
  • 認証: Authorization: Bearer <トークン> (/healthz のみ認証なし)。トークンは管理者に発行を依頼してください。
  • データの正本: rates.json — 適用開始月ごとの版管理、出典URL、検証済みフラグつき
  • Go 製・外部依存なし。同じコードを Docker で運用しています。

REST API

月は YYYY-MM (支払月・対象月)。2016年より前の月はデータなしでエラーになります。

パス内容
GET /v1/rates指定月に適用される料率。month、prefecture (省略で全47都道府県)
GET /v1/revisions登録済みの全改定 (種別・適用開始月・出典・検証済みか)
GET /v1/grades標準報酬月額の等級表
GET /v1/calc/social健康保険・介護保険・厚生年金・子ども・子育て支援金/拠出金。month prefecture monthly_remuneration または standard_remuneration、age
GET /v1/calc/employment雇用保険。month wage industry (general / agri / construction)
GET /v1/calc/withholding源泉所得税 (復興特別所得税込み)。month amount (社会保険料等控除後) column (ko / otsu) dependents
GET /v1/calc/payroll社保・雇用保険・源泉・住民税の控除と手取り、会社負担。gross prefecture age non_taxable_commute dependents column resident_tax

例: 東京都・標準報酬月額 30万円・45歳 (2026年4月)

curl -H "Authorization: Bearer $TOKEN" \

MCP

MCP は https://payroll-api.paps.jp/mcp (HTTP POST、Bearer トークン必須)、またはローカルバイナリの stdio で使えます。

# Claude Code
claude mcp add --transport http payroll-api https://payroll-api.paps.jp/mcp \
  --header "Authorization: Bearer <トークン>"
// stdio (Claude Desktop など): go build -o payroll-api ./cmd/server
{ "mcpServers": { "payroll-api": { "command": "/path/to/payroll-api", "args": ["-stdio"] } } }
ツール内容
get_rates指定月の適用料率
list_revisions全改定の一覧 (出典・検証済みフラグ)
get_standard_remuneration_grade報酬月額から等級・標準報酬月額
calculate_social_insurance社会保険料の本人・事業主負担
calculate_employment_insurance雇用保険料
calculate_withholding_tax源泉所得税 (甲欄・乙欄)
calculate_payroll_deductions控除合計と手取り、会社負担
check_for_revisions公式ページと突き合わせて改定・相違を検知

厚生年金2015-09〜日本年金機構
子ども・子育て支援金2026-04〜 (0.23%)協会けんぽ
子ども・子育て拠出金2015-04〜日本年金機構

源泉所得税2016年分〜国税庁『源泉徴収のあらまし』

すべての版に出典URLとverifiedフラグがあり、/v1/revisions で確認できます。源泉所得税は、国税庁の計算例と税額表の値 240 件を全年分で自動テストにかけ、再現を確認しています。

計算の考え方

  • 端数処理: 本人負担は 50銭以下切捨て・50銭超切上げ。事業主負担は 総額(四捨五入) − 本人負担。
  • 介護保険: 40歳以上65歳未満。75歳以上は健康保険なし、70歳以上は厚生年金・拠出金なし。
  • 厚生年金の標準報酬: 健康保険の標準報酬を 88,000〜650,000円に収めて算出。
  • 源泉所得税: 甲欄は国税庁の「電算機計算の特例」、乙欄は電算機計算の算式。税額表の値とは差が出ることがあり、年末調整で精算されます。
  • 住民税: 自治体の特別徴収通知額を resident_tax に入力 (計算はしません)。

注意事項

計算結果は目安です。実際の給与計算では、必ず最新の公式資料(協会けんぽ・日本年金機構・厚生労働省・国税庁)で確認してください。
  • 協会けんぽ管掌のみ。組合健保・共済は対象外です。
  • 賞与、随時改定、産休・育休の免除、労災保険、年末調整、日額表は未対応です。
  • 標準報酬月額の等級表の境界額、平成28年度(2016-03)の健康保険料率、拠出金率の 2015-04 / 2016-04 は、出典が弱いため未確認として扱っています (レスポンスの unverified_rate_kinds に出ます)。
  • 令和2〜7年分の乙欄は、国税庁の算式が月額表と約29万〜43.7万円付近の一部の行で最大数千円ずれます (算式のほうが大きい)。令和8年分は全行一致です。

改定への追従

料率が改定されたら、rates.json に新しい版を追記するだけです (過去の版は消しません)。ratecheck が協会けんぽ・厚生労働省・国税庁の公開状況を確認し、データとの相違や未登録の改定を検知します。

go run ./cmd/ratecheck   # 要確認があれば終了コード 1

詳しい手順は README を参照してください。
