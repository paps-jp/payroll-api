使い方を見る
WHAT

こんなことができます

給与計算でいつも調べているものを、ひとつの窓口にまとめました。「何月の給料か」「どの都道府県か」を伝えるだけで、その時点で正しい率と金額が返ってきます。

社会保険料

健康保険・介護保険・厚生年金・子ども・子育て支援金。本人と会社、それぞれの負担額を出します。

雇用保険料

一般・農林水産・建設の区分ごとに、働く人と会社の負担を計算します。年の途中で変わった年にも対応。

源泉所得税

毎月の給与から引く所得税(復興特別所得税込み)。扶養の人数による違いや、副業先(乙欄)にも対応。

手取りまで一括

上の全部をまとめて引き算し、手取り額と会社の負担総額まで一度に計算します。

過去の月にも対応

「2019年10月の給与」のように月を指定でき、その月の率で計算します。2016年から遡れます。

改定を見逃さない

公式サイトの発表と手元のデータを自動で見比べ、ズレや新しい改定があれば知らせます。

HOW TO USE

自分のプログラムやAIから使う

上の計算は、公開しているAPIを使っています。無料・登録・合言葉は不要です。ただし、短時間に大量のアクセスがあると制限がかかります(1分あたり120回まで。繰り返すと一時的に止まります)。

月と条件を伝える

「何月の給与か」「都道府県」「金額」「年齢」などを、URLの後ろに書いて送ります。

結果を受け取る

項目ごとの率・金額・本人と会社の負担が、整った形(JSON)で返ってきます。

AIにもつなげられる

MCPという仕組みでつなぐと、AIアシスタントに話しかけるだけで計算してもらえます。

プログラムから(API)

curl "https://payroll-api.paps.jp/v1/calc/payroll?month=2026-05&prefecture=東京都&gross=320000&age=35&dependents=1&resident_tax=15000"

AIアシスタントから(MCP)

MCPは、AIが外部の道具を直接使うための共通の仕組みです。つないでおくと、「2024年4月の東京の月給30万円の保険料は?」と話しかけるだけで、AIがこのAPIを呼んで答えます。

claude mcp add --transport http payroll-api https://payroll-api.paps.jp/mcp

GLOSSARY

むずかしい言葉の説明

給与計算に慣れていなくても読めるように、よく出てくる言葉をまとめました。

額面(総支給額)と手取り

額面は、保険料や税金を引く前の給与の合計です(通勤手当も含みます)。手取りは、そこから保険料・税金を引いて、実際に振り込まれる金額です。

標準報酬月額(ひょうじゅんほうしゅうげつがく)

社会保険料を決めるための「ざっくり月給」です。実際の月給を50段階ほどの区分(等級)に当てはめた金額で、保険料はこの金額に率をかけて出します。

本人負担と事業主(会社)負担

社会保険料は、働く人と会社が半分ずつ負担します(子ども・子育て拠出金だけは会社が全額)。給与から引かれるのは「本人負担」の分です。

介護保険料

40歳から64歳の人だけが払う保険料です。健康保険料に上乗せされます。

源泉所得税 / 甲欄・乙欄

毎月の給与から、会社が代わりに国へ納める所得税です。甲欄はメインの勤め先(扶養の届出を出している場合)、乙欄は副業先など届出がない場合の計算方法で、乙欄のほうが税率は高めです。

住民税

住んでいる自治体から会社に毎年通知が届き、毎月ほぼ同じ金額を給与から引きます。金額は自治体が決めるため、計算ではなく、通知の金額を入力してもらいます。

年末調整

1年間に引いた所得税を、年末にまとめて精算する手続きです。毎月の所得税が多少ずれても、ここで調整されます。

Q&A

よくある質問

本当に無料? 登録は必要?

無料で、登録も合言葉も要りません。ただし全員が快適に使えるよう、短時間に大量のアクセスがあった場合は制限します(1分あたり120回まで。繰り返すと一時的にブロック)。

入力した内容は保存される?

保存しません。入力された金額や年齢は計算にだけ使い、記録には残しません。

計算結果をそのまま給与に使ってよい?

あくまで目安です。実際の給与計算では、最新の公式資料(協会けんぽ・日本年金機構・厚生労働省・国税庁)でも確認してください。

自社の健康保険組合(組合健保)でも使える?

いいえ。対象は「協会けんぽ」に加入している会社です。組合健保や共済は率が違うため、対象外です。

ボーナス(賞与)や年末調整は計算できる?

まだできません。毎月の給与に対応しています。年収で入力した場合は、ボーナスなしで12か月に均等に割った計算になります。そのほか、産休・育休中の免除、労災保険、日額表も未対応です。

料率が変わったらどうなる?

新しい率を「適用開始月つき」で追加するだけで、過去の月は昔の率のまま、新しい月は新しい率で計算されます。公式サイトとの照合は毎週自動で行い、改定を見つけたら知らせます。

ご利用上の注意計算結果の正しさは保証できません。法令や公式の発表が優先されます。重要な判断には、社会保険労務士や税理士などの専門家にご相談ください。
